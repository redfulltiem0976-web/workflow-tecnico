WorkFlow Técnico

Coordina órdenes de trabajo con un tablero Kanban arrastrable, checklist de intervención y bitácora de cada cambio.

1. Instala Node.js 22.13 o posterior.

Comprueba en la terminal con node -v.

2. Abre esta carpeta y ejecuta la app.

En Windows, doble clic en INICIAR_WINDOWS.bat. Alternativamente, ejecuta node server.js en la terminal de esta carpeta.

3. Abre la aplicación.

http://127.0.0.1:3001/ (solo funciona mientras el servidor está encendido).

4. Demuestra la lógica.

Prueba las acciones de la web. Ejecuta npm test para verificar las funciones.

Los datos son ficticios. No afirma relación con una empresa específica ni que el sistema esté alojado en internet.
